# Security

Farframe talks to a PlayStation on your own network using credentials that
never leave your device. Keeping that promise matters more to us than any
feature, so please report anything that might weaken it.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

- Use GitHub's private vulnerability reporting on this repository
  (Security tab, "Report a vulnerability"), or
- email `support@unshackledpursuit.com` with "Farframe security" in the subject.

Include the release tag or App Store build, the platform, a minimal
reproduction, and what you believe the impact is. You will get a reply, and
credit if you want it, once the fix ships.

## What this repository never contains

Signing identities, provisioning profiles, Apple Team identifiers, App Store
Connect records, PlayStation account identifiers, Link Device codes,
registration keys, tokens, cookies, private-network addresses, hardware
addresses, device identifiers, and customer data. Every publication is a
history-free export that is audited for all of the above before it is pushed.
If you find something that slipped through, report it the same way.
